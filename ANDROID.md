# Findly для Android — как собрать приложение (APK)

Приложение — это тот же Findly, упакованный в настоящее Android-приложение (технология Capacitor):
своя иконка, экран загрузки, кнопка «Назад», доступ к микрофону и камере, без адресной строки браузера.
**Папка `android/` — это готовый проект для Android Studio.**

---

## 1. Один раз подготовьте компьютер

1. **Node.js версии 22 или новее.** Откройте nodejs.org, скачайте «LTS» и установите.
   Проверка: в Терминале `node -v` — должно быть `v22…` или выше.
   (Если стоит v20 — команды Android ниже выдадут ошибку «requires NodeJS >=22», просто обновите Node.)
2. **Android Studio** (developer.android.com/studio) — актуальная версия (Narwhal 2025.1.3 или новее).
   При первом запуске выберите «Standard» и согласитесь на загрузку Android SDK.
   Если позже Studio предложит обновиться или докачать «Android SDK Platform 36» — соглашайтесь.

## 2. Подготовьте проект (делайте при каждом обновлении)

В Терминале, в папке `findly`:

```bash
npm install            # скачать библиотеки (после каждого обновления архива)
npm run android:sync   # собрать сайт и положить его внутрь Android-проекта
npm run android:open   # открыть проект в Android Studio
```

* Файл `.env` с ключами Supabase **должен лежать в папке findly** — ключи «вшиваются» в приложение
  именно на шаге `android:sync`. Без него приложение будет писать «Failed to fetch».
* `npm run android:open` можно заменить вручную: Android Studio → File → Open → папка `findly/android`.
* **Шаг `android:sync` обязателен перед каждой новой сборкой APK**, иначе в приложение попадёт старая версия.

## 3. Первая сборка

В Android Studio подождите, пока внизу закончится «Gradle sync» (первый раз 5–15 минут: скачиваются компоненты).

**Запустить на телефоне напрямую (удобнее всего):**
1. На телефоне: Настройки → «О телефоне» → 7 раз нажать на «Номер сборки» → появится «Для разработчиков».
2. «Для разработчиков» → включить «Отладка по USB». Подключите телефон кабелем, разрешите отладку.
3. В Android Studio вверху выберите ваш телефон и нажмите зелёный треугольник ▶ (Run).

**Получить файл APK (чтобы скинуть другим или поставить без кабеля):**
1. Меню Build → Build Bundle(s) / APK(s) → **Build APK(s)**.
2. Справа внизу появится «APK(s) generated» → ссылка **locate**. Файл:
   `findly/android/app/build/outputs/apk/debug/app-debug.apk`
3. Перекиньте файл на телефон (Telegram «Избранное», Google Диск, кабель), откройте его и разрешите
   «Установку из этого источника».

## 4. Если приложение нужно раздавать другим людям (подписанная версия)

Build → **Generate Signed App Bundle / APK** → APK → «Create new…» (создайте ключ) → выберите **release** → Finish.
Готовый `app-release.apk` появится в `android/app/release/`.
**Файл ключа (.jks) и пароли сохраните в надёжном месте** — потеряете, и обновить приложение у людей будет нельзя.

## 5. Как обновлять приложение

Измените/получите новые файлы → **шаг 2** (`npm install`, `npm run android:sync`) → соберите APK заново и
установите **поверх** старого (данные и вход сохранятся).
Перед сборкой увеличивайте `versionCode` на 1 в файле `android/app/build.gradle` (строка `versionCode 1` → `2` и т.д.),
иначе Android может отказаться ставить «ту же» версию поверх.

### Необязательно: обновления без переустановки APK
Можно сделать так, чтобы приложение каждый раз загружало **живой сайт с GitHub Pages**. Тогда после обычного
Commit → Push новая версия появится у всех, кто открыл приложение, без пересборки APK.
В файле `capacitor.config.json` добавьте блок `server` (замените `ЛОГИН` на ваш логин GitHub):

```json
{
  "appId": "com.findly.app",
  "appName": "Findly",
  "webDir": "dist",
  "server": { "url": "https://ЛОГИН.github.io/Findly/" }
}
```
Затем `npm run android:sync` и соберите APK один раз. Минусы: нужен интернет даже для запуска, а скорость
зависит от сети. Этот режим я проверить на реальном телефоне не мог — если что-то поведёт себя странно,
удалите блок `server` и пересоберите (по умолчанию файлы лежат внутри приложения).

## 6. Что отличается в приложении от сайта

* По умолчанию включён **iOS-стиль** (меняется в Настройки → Оформление). На ПК остаётся прежний вид.
* Кнопка «Назад» закрывает окно/чат по очереди и только потом сворачивает приложение.
* «Скачать» файл/фото открывает ссылку в системном браузере, откуда файл сохраняется; «Скачать .txt» открывает меню «Поделиться».
* Микрофон и камера спрашивают разрешение при первом использовании (потом — Настройки телефона → Приложения → Findly → Разрешения).

## 7. Частые проблемы

| Симптом | Что делать |
|---|---|
| `The Capacitor CLI requires NodeJS >=22` | Обновите Node.js до 22+ (см. пункт 1) |
| В приложении «Failed to fetch» | Нет файла `.env` рядом с `package.json` при `npm run android:sync`; создайте его и повторите |
| Белый экран / «Unable to load asset» | Не выполнили `npm run android:sync` |
| Gradle: «SDK location not found» / не хватает Platform 36 | Android Studio → Settings → Languages & Frameworks → Android SDK → отметьте «Android 16 (API 36)» → Apply |
| Gradle: ошибка про версию Java | Settings → Build, Execution, Deployment → Build Tools → Gradle → **Gradle JDK** = `jbr-21` (встроенная в Studio) |
| Телефон не виден в Studio | Включите «Отладка по USB», разрешите отладку на экране телефона, смените кабель |
